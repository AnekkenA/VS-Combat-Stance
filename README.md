# VS: Combat Stance (Minecraft 1.21.1 NeoForge)

Официальное боевое дополнение для мода **Voxel Stand**.
Объединяет в себе систему боевых искусств (комбо, свитки, анимации) и тактических элитных врагов (ночные патрули, гарпуны, ростовые щиты).

## Требования
* **Voxel Stand (`voxelstand`)** — **СТРОГО ОБЯЗАТЕЛЕН** (`mandatory = true` в `neoforge.mods.toml`). Без него дополнение не запустится.
* **playerAnimator** (NeoForge 1.21.1) — библиотека процедурных анимаций тела игрока.
* **GeckoLib 4** (NeoForge 1.21.1) — библиотека скелетных анимаций сущностей.

## Особенности
1. **Боевые искусства (Arts)**:
   * **Стойка мастера (Martial Stand)**: верстак для изучения свитков и настройки 3 активных боевых стоек.
   * **Свитки техник**: 15 приемов (выпады, круговой вихрь, теневой шаг) и 10 тактических связок (парирование, глухая стойка, обманные маневры).
   * **Комбо-цепочки**: 4-ударные комбинации с синергиями и бонусами урона.
   * **Связка с Voxel Stand**: скорость анимаций ударов и уворотов напрямую считывает физический вес оружия через DataComponents (легкие клинки атакуют молниеносно, тяжелые молоты пробивают щиты).

2. **Элитные ночные враги (Threats)**:
   * **Элитный страж (Elite Guard)**: бронированный противник со скелетными анимациями GeckoLib, ростовым щитом (пробиваемым только топорами или тяжелым оружием из Voxel Stand с весом >= 350) и гарпуном на цепи.
   * **Ночные карательные патрули**: спавнятся в полночь под открытым небом.
   * **Боевой рог орды (War Horn)**: предмет для тактического призыва элитного отряда.

## Сборка
* **Minecraft**: 1.21.1
* **NeoForge**: 21.1.264+
* **Java Toolchain**: Java 21
* Сборка проекта:
```bash
./gradlew build
```
Готовый JAR-файл создается в папке `build/libs/`.
